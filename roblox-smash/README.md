# スカイ乱闘（仮称）

Robloxで動く、対戦アクションゲームです。攻撃を当てて相手の％をため、ステージの外まで吹っ飛ばします。

- 攻撃を当てるほど相手の％が上がり、％が高いほど大きく吹っ飛ぶ
- 画面の外まで飛ばされると残機が1つ減る（残機は3つ）
- 最後まで残った人の勝ち。3分で決まらなければ、残機が多い人の勝ち
- 2段ジャンプ、弱い攻撃、強い攻撃（スマッシュ）
- パソコン・スマホ・コントローラーに対応

キャラクター・名前・音・絵は、すべてRobloxの標準のものだけを使っています。他社のゲームのキャラクターや名前は入れていません。

## Roblox Studio への入れ方

1. Roblox Studio を開き、「Baseplate」で新しく作る
2. 右のエクスプローラーで **ServerScriptService** を右クリック →「オブジェクトを挿入」→ **Script**
   中身を全部消して、`src/server/SmashServer.server.luau` の中身を貼る
3. **StarterPlayer** の中の **StarterPlayerScripts** を右クリック →「オブジェクトを挿入」→ **LocalScript**
   中身を全部消して、`src/client/SmashClient.client.luau` の中身を貼る

ステージや床は、スクリプトが自動で作ります（最初からある床は自動で消します）。

## 試し方

対戦ゲームなので、2人以上で試合が始まります。

- 上の「テスト」タブ →「クライアントとサーバー」→ プレイヤー数を **2** にして「開始」
- 1人で「プレイ」を押した場合は、練習（動きと攻撃の確認）だけできます

| 操作 | パソコン | スマホ |
|---|---|---|
| 移動 | A / D | スティック |
| ジャンプ（2回まで） | スペース | ジャンプボタン |
| 攻撃 | クリック または J | 「攻撃」ボタン |
| スマッシュ | K または E | 「スマッシュ」ボタン |

## 調整のしかた

`SmashServer` の一番上にある `CONFIG` の数字を変えます。

| 項目 | 意味 |
|---|---|
| `MinPlayers` | 試合を始める人数 |
| `Stocks` | 残機 |
| `MatchSeconds` | 1試合の長さ（秒） |
| `Attacks` の `Damage` | 1発でたまる％ |
| `Attacks` の `Base` / `Scale` | 吹っ飛ぶ強さ ＝ Base ＋ ％ × Scale |
| `Blast` | やられる範囲（ここを越えると残機が減る） |

## 公開のしかた

1. 「ファイル」→「Robloxに公開」で、名前と説明を入れる
2. 体験の内容についてのアンケートに答える（殴り合いがあるので、暴力の項目は正直に答える）
3. 公開設定を「公開」にする

## いまの状態

- 文法のチェックは通っています。**Roblox Studio で実際に動かす確認はまだです。** 最初に動かしたときに、吹っ飛ぶ強さやカメラの位置などの調整が必要になるはずです
- 攻撃のモーション（腕を振る・体を傾ける）と、当たったときの赤い光、やられたときののけぞりが入っています。標準のアバター（R15）用で、R6など別の体型では動きません
- 効果音、キャラクターごとの技は入っていません
- 吹っ飛びは、飛ばされる本人の端末で動かしています。不正なプログラムを使うと吹っ飛びを無効にできるので、人が増えてきたら対策が必要です

## これから足すと面白くなるもの

- 攻撃のモーションと効果音
- キャラクターの種類（速い・重い・遠くから攻撃できる など）
- ステージの種類、アイテム
- 勝った回数で手に入る見た目のアイテム（収益化の入口）
