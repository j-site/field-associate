# ScanFix

3Dスキャンデータ（OBJ / STL / PLY）を読み込み、3Dプリント用に修復・調整してから
STL / OBJ で書き出すブラウザツール。サーバー不要、GitHub Pages にそのまま載ります。

公開先: `https://j-harvard.com/scan3d/`

## できること

スマホの3Dスキャンアプリなどの出力は、そのまま3Dプリントすると失敗しやすい問題を
抱えていることが多いです。ScanFix はそれをブラウザ上でチェック・修復します。

- **プリント適性チェック**：水密性（穴）・法線の向き・孤立した破片・重複頂点を自動検査
- **近接頂点を結合**：スキャン特有の微小な重複・隙間をまとめて位相を復元
- **孤立した破片を除去**：本体から浮いた小さなノイズ片を削除
- **法線を統一**：裏返った面を検出し外向きに揃える
- **穴を塞ぐ**：境界ループを検出し、平面的な穴を三角形分割で埋めて水密化
- **軽量化**：見た目をほぼ保ったまま面数を削減（three.js の Simplify を使用）
- **実寸スケール／底面接地**：最大辺を指定mmに合わせ、プレート面（Z=0）に接地

## 仕組みとできないこと

- **本格的なフォトグラメトリ（写真から3D復元）はできません。** これは既にスキャン済みの
  メッシュ（OBJ/STL/PLY）を対象にした後処理ツールです。スキャン自体はスマホアプリ
  （Polycam等）や専用スキャナで行ってください。
- 穴埋めはループが平面に近い単純な形状を想定しています（境界頂点300点まで）。巨大な
  欠損（メッシュの大部分が抜けている等）は対象外です。
- 修復アルゴリズム（`mesh.js`）は three.js に依存しない素朴な実装で、位置配列
  （Float32Array）とインデックス配列（Uint32Array）だけを扱います。ロジックは
  Node.js からも単体テストできます。

## ファイル構成

```
scan3d/
├── index.html    画面（マークアップとスタイル）
├── app.js        three.jsシーン・UI配線
├── mesh.js       メッシュ修復アルゴリズム（three.js非依存）
└── vendor/three/ three.js本体と使用するjsmモジュール（CDN非依存で同梱）
```

## 動作確認

穴・孤立した破片・重複頂点を意図的に仕込んだ立方体OBJでの検証で、
「読み込み→孤立破片の除去→穴埋め→法線統一→軽量化→STL/OBJ書き出し」まで
一通り確認済みです。書き出したSTLを独立に再パースし、水密（境界エッジ0・非多様体エッジ0）
になっていることも確認しています。
