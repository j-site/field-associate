# オクルダケ（仮称）

LINEに書類を送るだけで、AIが「これは何か・お金の影響・やること」を返します。
新しいアプリを覚える必要はありません。いつものLINEで、写真かPDFを送るだけです。

業種ごとの読み解き方は「業種パック」というファイルで足せます。プログラムは書けなくても、仕事のやり方を文章で書ければ作れます。

## できること

| 送るもの | 返ってくるもの |
|---|---|
| 書類の写真、PDF | これは何か／お金の影響／やること・期限／（必要なら）返信の下書き |
| 文章での相談 | 同じ形の答え |
| 「使い方」 | 使い方の説明 |
| 「パック作成 （仕事の内容）」 | その仕事用の業種パックの案 |

送信・支払い・申込みはしません。下書きを作るところまでで、実行するのは本人です。

## 付属の業種パック

| ファイル | 対象 |
|---|---|
| `packs/general.md` | 銀行・保険・役所・取引先からの書類（業種を問わない） |
| `packs/ooya.md` | 大家・小さな不動産会社 |
| `packs/machikoba.md` | 町工場 |
| `packs/kenchiku.md` | 建築・リフォーム |

届いた書類にどのパックを使うかは、AIが自動で選びます。利用者が選ぶ必要はありません。

## はじめ方

必要なものは3つです。

1. **LINE公式アカウント**（Messaging API）
   [LINE Developers](https://developers.line.biz/) でチャネルを作り、「チャネルシークレット」と「チャネルアクセストークン（長期）」を控えます。
2. **ClaudeのAPIキー**
   [Claude Console](https://console.anthropic.com/) で作ります。利用した分だけ料金がかかります。
3. **置き場所**（下のどちらか）

### A. Vercel に置く（サーバーの管理が要らない）

1. このフォルダを自分のGitHubに置き、[Vercel](https://vercel.com/) で読み込む
2. Vercel の設定で、環境変数を3つ入れる
   `LINE_CHANNEL_SECRET` / `LINE_CHANNEL_ACCESS_TOKEN` / `ANTHROPIC_API_KEY`
3. LINE Developers の Webhook URL に `https://（あなたのドメイン）/api/line` を入れ、「Webhookの利用」をオンにする
4. LINE公式アカウントの「応答メッセージ」をオフにする（オンのままだと自動応答と二重に返ります）

### B. 自分のサーバーに置く

```bash
npm install
cp .env.example .env    # 3つの値を入れる
node --env-file=.env server.mjs
```

Webhook URL は `https://（あなたのサーバー）/api/line` です。LINEはhttpsでしか届かないので、httpsで公開してください。

## 業種パックを足す

`packs/` に、次の形のファイルを1つ置くだけです。

```markdown
---
id: tosou
name: 塗装屋パック
author: 作った人の名前
description: どんな仕事の、どんな書類に使うかを1文で
---
## よく届く書類
## 読み解き方
## 出す結果
```

書き方がわからなければ、LINEで「パック作成」に続けて仕事の内容を送ると、AIがこの形の案を作って返します。案はログ（と、設定していればデータベース）に残るので、運営者が内容を確認して `packs/` に置けば登録完了です。自動では登録されません。

## 利用の記録と、パックの作者への分配

どのパックが何回使われたかを、1件ごとに記録します。これが、パックを作った人に使用料を分ける元の数字になります。

- 何も設定しなければ、ログに1行ずつ出ます
- `SUPABASE_URL` と `SUPABASE_SERVICE_KEY` を入れ、`schema.sql` を実行すると、表に保存されます。`okuru_pack_usage` で、パックごとの月別の利用回数と利用者数が見られます

記録するのは「いつ・どのパック・誰（LINEのIDを変換した文字列）」だけです。書類の中身は記録しません。
支払いそのものは、この仕組みには入っていません。回数を見て、運営者が振り込む形です。

## 設定

| 環境変数 | 必須 | 内容 |
|---|---|---|
| `LINE_CHANNEL_SECRET` | ○ | LINEのチャネルシークレット |
| `LINE_CHANNEL_ACCESS_TOKEN` | ○ | LINEのチャネルアクセストークン |
| `ANTHROPIC_API_KEY` | ○ | ClaudeのAPIキー |
| `CLAUDE_MODEL` | | 使うモデル。既定は `claude-fable-5-2`。費用を抑えるなら `claude-opus-5-5` や `claude-sonnet-5-5` |
| `CLAUDE_EFFORT` | | 考える深さ。`low` / `medium`（既定）/ `high`。深いほど遅く、高くなる |
| `SUPABASE_URL` / `SUPABASE_SERVICE_KEY` | | 利用の記録を保存する場合 |

## 配る前に決めておくこと

- **個人情報**：届く書類には、名前・住所・口座・契約の内容が入っています。書類はこのサーバーには保存しませんが、読み解くためにClaudeのAPIへ送られます。利用者にそのことを伝え、同意を取ってください。プライバシーポリシーも用意してください。
- **AIは間違えます**：数字の読み違いは起こります。お金や期限に関わることは、必ず元の書類で確かめるよう利用者に伝えてください。
- **専門家の仕事との線引き**：税金・法律・保険の個別の判断を有料で行うと、資格が必要な業務にあたることがあります。このサービスは「書類の内容を整理して伝える」までにとどめています。
- **費用**：利用者が送るたびにAPIの料金がかかります。月額料金は、1人あたりの送信回数を見てから決めるのが安全です。

## テスト

```bash
npm test
```

LINEとClaudeを偽物に差し替えて、署名の確認、写真・PDFの受け渡し、パックの選択、返信、利用の記録までを確かめます。本物のLINEとClaudeにつないだ確認は、鍵を設定したうえで各自で行ってください。
