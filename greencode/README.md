# greencode

プログラムの消費エネルギーとCO2を計測し、改善前後を比較するツール。

調査・実証実験・事業化の検討は [REPORT.md](./REPORT.md) を参照。

## 使い方

```bash
# コマンドを計測する
python3 greencode.py run -- python3 my_batch.py

# 改善前後を比較する（--units で1件あたりの値も出す）
python3 greencode.py compare --units 10000 \
  --before "python3 old.py" \
  --after  "python3 new.py"
```

```
■ 比較
  エネルギー  25.4倍 効率化（96.1% 削減）
  経過時間    25.9倍 高速化
```

| オプション | 内容 |
|---|---|
| `--repeat N` | N回実行して中央値を採用（既定 3） |
| `--units N` | 処理件数。1件あたりのエネルギー・CO2（SCI）を出す |
| `--watts W` | 推定時のCPU1コアあたり電力（既定 8W） |
| `--grid G` | CO2排出係数 kg-CO2/kWh（既定 0.421） |
| `--json` | JSONで出力 |

## エネルギーの算出方法

出力には必ずどちらの方法かが表示されます。

- **実測** — Linuxで電力センサー（RAPL）が読める場合。CPUパッケージ全体の消費電力量
- **推定** — 読めない場合（仮想マシン・コンテナ・macOS）。CPU時間 × 1コアあたり電力

同じマシンでの改善前後の比較は推定でも概ね成り立ちますが、絶対値は目安です。
ディスク待ちや通信待ちはCPU時間に現れないため、I/Oの多い処理では推定値は控えめに出ます。

失敗したコマンドは計測せずエラーにします（壊れた処理の「省エネ」には意味がないため）。
