# オートパイロット（自主運転）

人が指示しなくても、決まった時刻にAIが仕事を進める仕組みです。
「調べて、下書きを作るところまで」を自動で行い、判断・送信・支払い・公開は人が行います。

## 3つの定期実行

| 名前 | いつ | 何をするか | 結果の届き方 |
|---|---|---|---|
| 事務 | 毎朝 6:50 | Gmail と カレンダーを確認し、返信の下書きを作り、期限を知らせる | スマホへの通知＋セッションの報告。下書きは Gmail の下書きに入る |
| 開発 | 月・水・金 21:40 | `BACKLOG.md` の先頭の仕事を1つ進める（テストが通ったものだけ記録） | スマホへの通知＋このリポジトリのコミット |
| 調査 | 毎週月曜 6:35 | `RESEARCH.md` の先頭の題材を1つ調べて、報告にまとめる | スマホへの通知＋セッションの報告 |

別に動いている「Jarvis」（毎朝5時の今日やること、物件ウォッチなど）とは役割を分けています。
オートパイロットは、Field&Associate 宛のメールと、アプリ・ゲーム・新規事業を担当します。

## 舵の取り方

AIに頼みたいことは、次のファイルに書くだけです。

- `BACKLOG.md` … 開発の順番待ちの仕事。上にあるものから進む
- `RESEARCH.md` … 調べたい題材。上にあるものから調べる
- `RULES.md` … やってよいこと・いけないこと（全員が守る決まり）

## 止め方

Claude の「スケジュールされたタスク」の画面で、該当のタスクをオフにします。全部止めるなら3つともオフにします。

## 公開リポジトリです

このリポジトリは誰でも読めます。メールの中身、お金、保険、口座、個人情報は、**ここには書きません**。
事務の結果はセッションの報告とGmailの下書きにだけ残します。

## 設定の注意：事務に Gmail とカレンダーをつなぐ

「事務」は Gmail と Google カレンダーのツールが必要です。定期実行をこの仕組みから登録したときは、コネクタを付けられませんでした。
claude.ai の「ルーティン」の画面で「オートパイロット：事務（毎朝）」を開き、Gmail と Google Calendar のコネクタを追加してください。追加するまでは、事務は「ツールが使えない」と報告して終わります。

## 実行が止まったとき

モデルの利用枠（クレジット）が足りないと、サーバーが定期実行を止めて、そのタスクをオフにすることがあります。
朝の通知が来なくなったら、タスクがオンのままかを確認してください。
