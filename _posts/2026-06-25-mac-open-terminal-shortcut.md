title: "Macでターミナルを一発起動！ショートカットキーの設定方法"

デスクトップやFinderからターミナルを開くのに毎回Spotlight検索していませんか？Automatorを使えば、好きなショートカットキー（例: ⌥⌘T）でいつでもターミナルを起動できます。

## 手順

### 1. Automatorで「クイックアクション」を作成

1. Automator を起動 → **新規** → **クイックアクション** を選択
2. 「ワークフローが受け取る現在の項目」を **入力なし** に変更（重要！これをしないとサービスメニューに表示されません）
3. 左のアクション一覧から **「シェルスクリプトを実行」** をドラッグ
4. スクリプト欄に以下を入力：

```bash
open -a Terminal
```

5. **⌘S** で保存 → 名前を `OpenTerminal` に

### 2. ショートカットキーを割り当て

1. **システム設定** → **キーボード** → **キーボードショートカット**
2. **サービス** → **一般** の中に `OpenTerminal` が表示される
3. 好きなキー（例: **⌥⌘T**）を割り当て

これで完了です。どの画面からでも ⌥⌘T でターミナルが開きます。

## なぜ「アプリのショートカット」ではダメなのか

macOSの「アプリのショートカット」はメニュー項目名と完全一致する必要があり、ターミナル起動のような用途には向いていません。**サービス（クイックアクション）** として登録するのが最も確実な方法です。

## ポイント

- **「入力なし」の設定を忘れずに** — デフォルトの「自動（テキスト）」のままだとサービスメニューに表示されません
- iTerm2 を使っている方は `open -a Terminal` を `open -a iTerm` に変更すればOK
- 同じ手順で他のアプリも一発起動できます（VS Code、Finder など）
